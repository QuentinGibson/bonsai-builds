# Weapon-set allocation via toolbar toggle, matching the in-game UI

Weapon set 1 and 2 are allocated via a toolbar toggle — a "W1 / W2 / Both" selector that puts the user in a mode; clicks in that mode allocate nodes to the selected set. This matches the in-game approach and is self-explaining by label. The alternative — shift/ctrl modifier keys — was rejected because modifier key schemes require a tooltip to be discoverable, whereas the toolbar communicates the feature just by existing. All three allocation layers (main tree, set 1, set 2) remain visible simultaneously regardless of which mode is active; the toggle only controls which set new allocations go into. Deallocation always uses a plain click regardless of the active mode — the toolbar mode is allocation-only.
